Analizador de Texto

Extrae estadísticas y transforma texto usando métodos de String en JavaScript.

🎯 Tu misión: Analiza el texto ingresado y muestra estadísticas detalladas.

Debes aplicar:
  • const para el texto original y variables de análisis (no deben cambiar)
  • typeof para verificar que el valor leído sea string
  • Métodos de String: .length · .trim() · .split() · .toLowerCase() · .toUpperCase()
  • Contar palabras: texto.trim().split(/\s+/).length (expresión regular básica)
  • Contar oraciones: separar por split(/[.!?]+/) y filtrar vacíos
  • Calcular tiempo de lectura: promedio 200 palabras/minuto → Number resultado
  • Contador en tiempo real de caracteres mientras se escribe (evento input)
  • Transformaciones: MAYÚSCULAS, minúsculas, Titulo, invertir texto
