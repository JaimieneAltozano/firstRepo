# Landing Page (HTML y CSS)

## Proyect Overview

This project is a **starter template** for a performance assessment for a rock band.

The goal is to transform this base into a **visually engaging, and well-structured website** that promotes the band, their identity, and upcoming events.

## HTML Guidelines

The `index.html` already includes the base structure.

* Use semantic tags:

  * `<header>`
  * `<nav>`
  * `<section>`
  * `<article>`
  * `<footer>`

* Include the following sections:

  * Hero (main visual section)
  * Events (band tour dates)
  * About (band info)
  * Multimedia (images or media content)

* Add at least one **unordered list (`<ul>`)**:

  * Influences
  * Values
  * Social links

👉 Focus on **clean structure and readability**.

## CSS Guidelines

The provided `style.css` is intentionally minimal.

* Define own:

  * Colors (rock style recommended)
  * Typography
  * Spacing

* Apply layout techniques:

  * Flexbox
  * Grid
