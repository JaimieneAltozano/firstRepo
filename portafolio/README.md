### **1.**

**Title:** User login to view profile
**Description (User Story):**
As a user, I want to log in so that I can see my profile.

**Acceptance Criteria:**

* Given the login page is open, when I enter valid credentials, then I can access my profile.
* Given the login page is open, when I enter invalid credentials, then I see an error message.

**Tasks:**

1. Create login form.
2. Validate user credentials.
3. Redirect user to profile page.

**Priority:** High
**Status:** To Do
**Story points:** 3
