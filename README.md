# inventario.py

This is a simple Python program where the user can register products and calculate the total cost of the inventory.

## Description

At the beginning, the program shows a menu in the console. The user can choose an option to register products or calculate the total cost.

Each product has three attributes: name, price, and stock.

## Features

- Product registration
- Total cost calculation

## Usage

Choose one of the menu options and follow the instructions.  
First, you need to register one or more products.
